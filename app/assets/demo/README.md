# Demo-Vorlagen „Party / Geburtstag“

- `party-frame-1800x1200.png` – Rahmen Einzelfoto, 10×15 cm quer, 300 dpi
- `party-strip-1200x1800.png` – Doppel-Streifen (2 × 5×15 cm, je 3 Fenster), 10×15 cm hoch
- `party.json` – Slots und Text-Elemente der Vorlagen

Erzeugt mit `scripts/make-demo-frame.py`, installiert auf einer Box mit
`.venv/bin/python scripts/install-demo-template.py`.

**Lizenz:** Farbverlauf, Konfetti, Luftschlangen und Wimpelkette sind eigene
Formen. Die Emojis darin sind [Twemoji](https://github.com/jdecked/twemoji) –
